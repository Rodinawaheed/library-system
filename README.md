Library System
Overview
This project is a simple Library System developed using Java. It models the main entities of a library and demonstrates basic Object-Oriented Programming (OOP) concepts.
Project Model
The project includes the following classes and enums:
Book: Represents a book in the library.
BookStatus: Defines the possible statuses of a book: AVAILABLE and BORROWED.
Member: Represents a library member.
MemberType: Defines member types and their borrowing limits.
Loan: Represents a loan associated with a book and a member.
Lab4LibraryModel: Contains the current model demonstration.
